# Wiener Abfahrten – Alexa Skill

**Wann kommt meine Bim?** Wiener Abfahrten sagt dir die nächsten Abfahrten deiner Öffis in Echtzeit.

1. „Alexa, öffne Wiener Abfahrten"
2. Haltestelle, Linie und Richtung nennen – fertig.
3. Ab jetzt: „Alexa, frag Wiener Abfahrten, wann kommt die 62?"

Bis zu 10 Linien speicherbar: U-Bahn, Straßenbahn, Bus, Nachtbus und Badner Bahn.

| Befehl | Was passiert |
|---|---|
| „Wann kommt die U6?" | Nächste Abfahrten der U6 |
| „Wann kommt der Bus?" | Alle gespeicherten Buslinien |
| „Alle Abfahrten" | Alle gespeicherten Linien |
| „Linie hinzufügen" | Neue Linie einrichten |
| „Was habe ich gespeichert?" | Deine Liste |
| „Lösche die 62" | Linie entfernen |
| „Alles löschen" | Alle Daten löschen |
